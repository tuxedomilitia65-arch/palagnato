Introduction to BSCS

The Bachelor of Science in Computer Science (BSCS) is a degree program focused on computers, programming, software, algorithms, and problem solving using technology.

Program Description

BSCS covers programming, web development, databases, algorithms, software development, computer systems, and information security.

BUILD YOUR KNOWLEDGE

Skills You Can Develop

Programming

Programming is the process of writing instructions that tell a computer what to do. Students can learn languages such as Java, Python, and C++.

Web Development

Web development involves creating websites using HTML, CSS, and other web technologies. It combines design, structure, and functionality.

Database Management

Database management involves organizing, storing, retrieving, and maintaining information so it can be accessed and used properly.

Problem Solving

Problem solving helps students analyze situations, think logically, and find effective solutions using Computer Science concepts.

Software Development

Software development is the process of planning, designing, creating, testing, and improving computer programs and applications.

Computer Systems

Computer systems knowledge helps students understand hardware, software, operating systems, and how different computer components work together.
